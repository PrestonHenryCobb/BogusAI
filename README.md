# Fake Job Detector

A hackathon project (HackLanta 2026) that flags fraudulent job postings and recruiter messages, aimed at students. Trains on EMSCAD (2012-2014 real job-posting data) and evaluates against a hand-built "modern challenge set" of current scam patterns.

See [docs/LABOR_DIVISION.md](docs/LABOR_DIVISION.md) for how the team is split and [docs/BRANCHING.md](docs/BRANCHING.md) for the git workflow.

## Repo layout

```
data/
  raw/              # EMSCAD csv (committed -- private repo, see note below)
  processed/        # splits.json (committed, generated by src/pipeline)
  challenge_set/    # modern scam examples + hard negatives, WITH provenance column
notebooks/          # exploration notebooks
src/
  pipeline/         # loading, dedup, group split
  model/            # training, calibration, ablation tiers
  redflags/         # rule-based red-flag extractor
app/                # Streamlit demo app
  background.py     # embeds app/frontend's R3F background behind the UI
  frontend/          # React + three.js/R3F dithered-wave background (see below)
docs/               # writeups, labor division, limitations slide notes
```

## Setup

```bash
python -m venv .venv
source .venv/bin/activate  # or .venv\Scripts\activate on Windows
pip install -r requirements.txt
```

Place `fake_job_postings.csv` (EMSCAD, from the Kaggle "Real or Fake: Fake Job Posting Prediction" dataset) into `data/raw/`.

## Running the pipeline

```bash
python -m src.pipeline.build_splits     # dedupe + group split -> data/processed/splits.json
python -m src.model.train               # trains tiers A-C
streamlit run app/main.py               # demo UI
```

## App background (app/frontend)

The dithered wave behind the UI ([react-bits](https://reactbits.dev)'s `Dither`) is a small
React + three.js (`@react-three/fiber`, `@react-three/postprocessing`) scene, built to one
self-contained `dist/index.html` and embedded via `app/background.py` using
`st.components.v1.html`. The built file is committed, so running the demo needs no Node
install. Only rebuild it if you edit `app/frontend/src`:

```bash
cd app/frontend
npm install
npm run build        # writes dist/index.html -- commit the result
```
